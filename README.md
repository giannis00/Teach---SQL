# SQL teaching materials

Worksheets, table scripts and answers for a first course in SQL: selecting and filtering rows, sorting, changing data, and joining tables.

**Instructor:** Ioannis Tsioulis

## How to run the queries

- The worksheets on the *Students* and *Employees* tables and the joins lab ask you to work in the [Programiz online SQL editor](https://www.programiz.com/sql/online-compiler): paste the table script first, then write your queries. Nothing needs to be installed.
- The *Films* exercises use a Microsoft Access database, [Films.accdb](Films.accdb).

> **Looking for a complete course?** [*From One Table to a Cluster: Working with Data at Scale*](https://giannis00.github.io/teaching/#data-at-scale) on my website starts from SQL and goes on to data warehouses, NoSQL, Spark and streaming.
